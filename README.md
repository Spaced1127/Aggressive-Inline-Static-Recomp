# Aggressive Inline Static Recomp - GameCube (Windows)

A native Windows static recompilation of **Aggressive Inline** (GameCube, USA,
`GILE51`, Acclaim/Z-Axis). The recompiled module is generated by **DolRecomp**
and hosted by **ModernGekko**, the Dolphin-derived runtime used by the other
projects in this workspace.

This repository contains **no game data**. A legally dumped USA disc image is
required.

## Current status

The game boots and reaches playable gameplay:

- Z-Axis and Acclaim intro movies render (CRI h4m movie path).
- Main menu, player select, name entry, options, and level select all render
  with working text and 3D background scenes.
- The Tutorial level loads and renders: world geometry, reflections, skinned
  player character, HUD, and tutorial overlays.
- Controller input works with DualSense, DualShock, Xbox, Switch Pro, Steam and
  other SDL pads; the player moves with the main stick. The launcher has a
  CONTROLLER page with ready-made layouts and exact SDL device detection.
- Save states save and reload into gameplay.
- Audio output works through DSP LLE + Cubeb (user-confirmed; the earlier
  silence was a muted output).
- 59.9 FPS in windowed gameplay at 3x native (1920x1344) internal resolution
  with the Clang `-O3` module (`speed~0.999`).
- No crash or unimplemented-stub abort has been observed through the first
  level load.
- A standalone player release is staged in
  `dist/AggressiveInline-Recomp-v0.0.2-Windows-x64/` with a WinForms launcher,
  direct ISO/RVZ import, the Clang module and no game data.
- 16:9 widescreen and the Hor+ widescreen hack work in v0.0.2. The v0.0.1
  runner was a stale binary that ignored the aspect settings; the new runner is
  built from the current ModernGekko source.

Open issues are tracked in [`docs/STATE.md`](docs/STATE.md). Audio works; if
you hear silence, check the Windows volume mixer for `gile.exe`, the launcher's
Audio page, and the in-game Sound menu (SFX / Music / Speech). The remaining
known item is the missing zgui host function `inlineOverlayGetNumContinues`;
performance validation is ongoing.

## Requirements

- Windows 10/11 x64.
- Visual Studio 2022/2026 Build Tools with the C++ workload, CMake, Ninja.
- The DolRecomp + ModernGekko toolchain from
  `H:\Projects\SB-RFD\lib\ModernGekko-Template` and its build at
  `H:\Projects\SB-RFD\build\moderngekko`.
- Your own USA `GILE51` disc image (`.iso` or `.rvz`).

## Quick start

```powershell
# 1. RVZ -> ISO (skip if you already have an ISO)
python tools\rvz_extract.py "Aggressive Inline (USA).rvz" work\disc\game.iso

# 2. Extract the DOL and the disc tree
python tools\extract_dol.py work\disc\game.iso work\disc\main.dol
H:\Projects\SB-RFD\build\dolrecomp\dolrecomp.exe extract work\disc\game.iso work\game

# 3. Recompile + build a module (Clang is recommended; MSVC also works)
tools\build_clang.bat
tools\build_msvc.bat

# 4. Copy the chosen module back into the project
#    (the build scripts write to C:\gile to stay under MAX_PATH)
copy /Y C:\gile\modules-clang\GILE51\<cache>\gGILE51_recomp.dll build\gGILE51_recomp_clang.dll
copy /Y C:\gile\modules\GILE51\<cache>\gGILE51_recomp.dll       build\gGILE51_recomp.dll

# 5. Dev run (direct runner, Clang module)
tools\run_dev.bat

# 6. Build the player release
powershell -ExecutionPolicy Bypass -File tools\make_release_gile.ps1 -Version 0.0.3
```

`tools\run_dev.bat` starts the game in a window with the profile in
`work\user\Config\GCPadNew.ini`. The release launcher has a **CONTROLLER** page
with ready-made DualSense, DualShock, Xbox, Switch Pro, Steam and 8BitDo
layouts, plus an exact "Read from log" device picker.

## Release

`tools\make_release_gile.ps1` builds:

```
dist/AggressiveInline-Recomp-v0.0.3-Windows-x64/
dist/AggressiveInline-Recomp-v0.0.3-Windows-x64.zip
```

The stage contains `gile-launcher.exe`, `gile.exe`, the Clang module,
`rvz_extract.exe`, `Sys/`, the full `defaults/GCPadNew*.ini` preset set,
`LICENSES/`, `recomplauncher.json`, the player docs and an empty `game/` folder. The
launcher accepts an ISO, an RVZ or an extracted folder, verifies `GILE51` and
the DOL SHA-256, extracts to `%LOCALAPPDATA%\AggressiveInlineRecomp\game`, and
starts the game with the bundled module.

The v0.0.2 widescreen root cause and packaging results are recorded in
[`docs/notes/04-widescreen.md`](docs/notes/04-widescreen.md). The v0.0.3
controller layouts, exact SDL matching and packaging results are in
[`docs/notes/05-controllers.md`](docs/notes/05-controllers.md). The earlier
v0.0.1 packaging notes remain in
[`docs/notes/02-release.md`](docs/notes/02-release.md).

## Automated bring-up

`tools\auto_probe.ps1` runs the game headless with ModernGekko's automation
channel and saves screenshots to `work\evidence\`. Commands are also supported
for input (`pad_frames`), save states (`save_state`/`load_state`) and guest
memory (`read_memory`/`write_memory`).

```powershell
powershell -ExecutionPolicy Bypass -File tools\auto_probe.ps1 -Seconds 50 -Shots 10,25,45
```

## How it works

- **DolRecomp** decodes the GameCube DOL and emits portable C: 84 chunks,
  340,568 instructions decoded (2,368 in `text0`, 338,200 in `text1`),
  0 unknown.
- **ModernGekko** loads `gGILE51_recomp.dll` at `0x80005308` and supplies the
  Dolphin-derived GX, DSP, DVD, input and OS HLE layers.
- Default module: Clang `-O3` + `-march=x86-64-v3` + ThinLTO, loop budget 4096 /
  call depth 128. The MSVC `/O2` module remains as a fallback. PGO is a possible
  later pass for particle-heavy scenes.
